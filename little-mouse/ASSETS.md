# Assets

The original generated fur image is `assets-source/mouse-fur.png`; the game uses `public/assets/mouse-fur.jpg`.

Generated using the built-in image-generation tool. Prompt: "Use case: photorealistic-natural. Asset type: seamless square albedo texture for a realistic 3D house mouse fur material. Generate a flat orthographic extreme macro swatch of dense short fine gray-brown mouse fur, warm taupe with subtle charcoal and beige hair tips, hairs flowing predominantly top to bottom. Uniform even diffuse lighting, no highlights or shadows baked in, no objects, no face, no animal silhouette, no background, no text. Fill entire square edge to edge with highly detailed realistic short fur, seamless texture suitable for wrapping 3D geometry."

Geometry, skin textures, animation and backgrounds are generated by original project code. Three.js is MIT licensed; its license is included in the installed dependency.
