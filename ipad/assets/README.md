# App artwork

`icon.png` is the original two-cat illustration supplied by the owner for
**Podrick’s Violin**. It was copied without alteration from the provided attachment.
Expo's native asset pipeline creates a centered square crop for the iOS app icon;
both cats and the fish remain visible. The generated 1024×1024 icon was inspected.
The same original is configured as the native splash image on a dark ink background.
Keep the original here so native rebuilds can reproduce the icon without chat access.
No third-party artist attribution or license information was supplied with the image.
